## 🚀 Overview

SwitchCast **v1.2.0** is a major feature and stability release introducing full local media presentation (Images & Videos), high-fidelity video audio playback with volume controls, dedicated dock-controlled fullscreen presentation output, native non-client caption dragging for the Floating Presenter Dock, and a permanent resolution to the playback timeline cross-thread COMException.

---

## ✨ What's New in v1.2.0

### 🖼️ Full Media Presentation Integration (Images & Videos)
- **Direct File Import**: Presenters can now import local images (`.png`, `.jpg`, `.jpeg`, `.bmp`, `.gif`) and video files (`.mp4`, `.mkv`, `.mov`, `.wmv`, `.avi`) directly into the SwitchCast presentation queue.
- **Unified Presentation Queue**: Media sources seamlessly interleave with desktop application windows and physical monitors.
- **Native Video Playback**: Direct hardware-accelerated playback utilizing `Windows.Media.Playback.MediaPlayer` and `MediaPlayerElement`.

### 🔊 Local Media Audio Playback & Volume Control
- **Audible Local Playback**: Videos now produce audible local sound connected directly to Windows audio endpoints.
- **Mute & Volume Controls**: Dedicated volume slider (0–100%) and instant mute toggle (`\uE74F`/`\uE767`) on both the Control Dashboard and the Floating Presenter Dock.
- **Atomic Seek Synchronization**: Audio and video seek, pause, resume, and restart in perfect lockstep.

### 🖥️ Fullscreen Presentation Output
- **Dock-Controlled Fullscreen Toggle**: Switch between standard windowed mode and true borderless fullscreen (`AppWindowPresenterKind.FullScreen`) directly from the Floating Presenter Dock.
- **Same HWND Continuity**: Transitions preserve the identical Win32 HWND, active capture session, and media stream without interrupting meeting shares.
- **100% Viewport Coverage**: Title bar collapses automatically in fullscreen mode with 16:9 aspect ratio preserved. Press `Escape` to quickly exit fullscreen.

### 🎛️ Floating Presenter Dock Finalization
- **Native Caption Dragging**: Replaced custom pointer routing with genuine Windows App SDK `InputNonClientPointerSource` caption regions, eliminating sticky dragging or click-to-move anomalies.
- **Adaptive Video Transport Controls**: When a video source is on-air, the dock dynamically reveals timeline scrubber controls (Restart, Backward 10s, Play/Pause, Forward 10s, live timecode `mm:ss / mm:ss`).
- **Unified Toolbar Layout**: Streamlined 680 DIPs single-row baseline layout with instant source switching, mode selector, and fullscreen toggle.

### 🛡️ Critical Stability & Threading Hotfix
- **Permanent Elimination of `COMException 0x8001010E` (`RPC_E_WRONG_THREAD`)**:
  - Replaced background thread-pool timers with a single, UI-owned `Microsoft.UI.Dispatching.DispatcherQueueTimer`.
  - Enforced strict WinUI 3 UI thread affinity for all `PropertyChanged` notifications bound to XAML slider controls.
  - Eliminated unsafe fallback execution branches on worker threads.

## ⌨️ Default Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Shift + →` | Next Presentation Source |
| `Ctrl + Shift + ←` | Previous Presentation Source |
| `Ctrl + Shift + 1..5` | Direct Queue Switch (Sources 1–5) |
| `Ctrl + Shift + P` | Toggle Pause / Freeze-Frame |
| `Ctrl + Shift + B` | Toggle Blackout / Privacy Curtain |
| `Ctrl + Shift + S` | Stop Presentation |
| `Ctrl + Shift + D` | Toggle Floating Presenter Dock |
| `Ctrl + Shift + M` | Bring Dashboard to Foreground |
