## 🚀 Overview

SwitchCast **v1.2.1** is a focused usability, stability, and branding release. It delivers dedicated Presentation Output activation for media sources under Active + Live and Active Only modes, updates the official application icon with authentic multi-resolution Windows ICO branding, enhances Floating Presenter Dock focus handoff, fixes mixed-source queue navigation, and introduces direct source unqueuing from the dock.

---

## ✨ What's New & Fixed in v1.2.1

### 🖼️ Media Source Presentation Output Activation
- **Active + Live for Media**: When an imported Image or Video source is taken live in `Active + Live` mode, SwitchCast starts media playback and automatically activates the existing **Presentation Output** window (restoring if minimized and bringing it to the desktop foreground via Win32 `SetForegroundWindow`). No external media players (e.g. VLC or Photos) are launched.
- **Active Only for Media**: Navigating to an Image or Video source in `Active Only` mode advances the selection cursor and activates the Presentation Output window without altering the On-Air stream, without starting video playback, and without replacing the current audience-facing frame. If closed, the output opens in Standby mode.
- **Live Only Preserved**: Switching media sources in `Live Only` mode takes them live without stealing focus or requesting foreground focus.
- **Ordinary Window & Monitor Semantics Preserved**: Win32 window sources retain standard application activation, and display monitors retain display capture semantics.
- **Presentation State Continuity**: Reuses the active output instance without recreation, repositioning, or disrupting fullscreen presentations.

### 🎨 Authentic Multi-Resolution Application Branding
- **Official App Icon**: Packaged high-resolution source icon into standard multi-resolution `SwitchCast.ico` embedding **16x16, 24x24, 32x32, 48x48, 64x64, 128x128, and 256x256** resolutions.
- **Windows Shell Integration**: Seamless integration across Windows Explorer, taskbar, Alt+Tab, and WinUI 3 title bars.

### 🎛️ Floating Presenter Dock Enhancements & Stability
- **Focus Handoff Coordination**: Popup dropdown menu closes and detaches before executing source transitions, preventing dock teardown from stealing focus away from the activated presentation window.
- **Double-Click Maximize Prevention**: Subclassed dock HWND (`WM_NCLBUTTONDBLCLK` on `HTCAPTION`, `SC_MAXIMIZE` interception, `WM_GETMINMAXINFO` clamping) to guarantee the dock remains a compact, floating companion toolbar without accidental maximization.
- **Direct Source Unqueue**: Presenters can remove individual items directly from the "Queued Sources" dropdown using interactive checkmark checkboxes without stopping live presentations.
- **Dock X Dismissal Dashboard Activation**: Clicking the X button on the Floating Presenter Dock automatically restores and brings the Control Dashboard to the foreground while keeping live presentations and video playback completely running.

### 🔄 Mixed-Source Queue Navigation Fix
- Repaired Next/Previous queue cycling between Window, Monitor, Image, and Video sources by traversing a single authoritative ordered queue across all source types.

### ⏯️ Dynamic Presentation Button Glyphs
- Main Dashboard button icon dynamically synchronizes with presentation state, updating between Play (`\uE768`) and Stop square (`\uE71A`) in lockstep with the button label.
